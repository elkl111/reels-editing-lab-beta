# Reels Editing Lab

A Claude Code project that edits talking-head reels through conversation. Drop in a clip and say "edit this reel". Claude cuts out retakes, false starts and dead air, then you review the cut line by line in the chat. Claude then builds the finished reel in your look: captions, hooks, pop-up explainer graphics, zooms, sound effects and a cover.

- **Start here:** `SETUP.md`. Open the folder in the Claude desktop app (Code tab) and say "set me up".
- **The agent's rules:** `CLAUDE.md` and `.claude/skills/`. The skills are setup, new-reel, hooks and visuals.
- **The engine:** `tools/` (Python, run with `uv`) and `effects/` (the HTML graphics stage and its pop-up pieces).
- **Looks:** `packs/<kit>/kit.json`. Journal, Loud and Studio are the shareable presets and use free Google Fonts.
- **What broke and why:** `ENGINE-NOTES.md`. Read it before changing the engine.

Not in the repo: speech models (downloaded by `tools/get_models.py`), footage and projects, and private fonts.

Runs locally on Apple-chip Macs. Icons: Lucide (ISC). Sounds: generated by `tools/make_sfx.py`.
